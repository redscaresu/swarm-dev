## Decisions for v0.31.0 (the user, 2026-10-31)

1. **Local test runs.** No cap by default: the swarm will run on bigger machines, and the cap
   (`~/.swarm/test-cap`) stays opt-in, sized per machine. Fix instead: a builder notices when its
   own background run ends (several sat idle 15 to 80 minutes), and pushes once its own tests pass,
   letting CI run the full suite.
2. **Merge churn.** Both: `swarm.sh merge` runs the remerge-diff check itself on every merge of the
   base, whoever made it, and accepts the new head when it removes no line of the base; and it sends
   PRs through a merge queue where the repo has one. Moving swarm-dev to an org to get a queue is
   parked.
3. **`wait --lead`.** Fixed first in v0.31.0: it re-reads the board after each merge, never exits
   without a line, and checks a line still holds before printing it.
4. **Review stalls.** The reviewer follows the PR: when the head moves it reviews the new head
   instead of stopping, and it waits for the new commit, not the builder's turn.
5. **Also in v0.31.0:** agent start failures (#688: raise the start wait and retry), agent merges
   refused by the permission check (#699), sharing or caching the agents' GitHub polling so the API
   quota lasts, and codex capacity (reviews retry codex after a usage limit; raising the Foundry
   deployment's capacity is an Azure change the user approves separately).
