# swarm.sh retro: the command, its window, and the lead's memories

Add `swarm.sh retro [--since <tag>] [--memory <dir>]`: a read-only report that makes no gh call. Add a `retro)` dispatch arm beside flow, outcomes and dataset (bin/swarm.sh:650-652). Add a header line beside flow's (bin/swarm.sh:17-19). Add `retro` to READ_ONLY_COMMANDS (bin/swarm.sh:724), so it logs no event. retro_report goes in bin/lib/reports.sh. --since defaults to v<newest_tag origin/<base>> (bin/lib/board.sh:1396-1404). An unknown tag dies and names it. The window starts on the tag commit's day (`git log -1 --format=%cs <tag>`). The report's first lines name the tag, the window's day, and the swarm.sh that wrote it. The retro file has to record that (epic Constraints). Name it by `git -C SWARM_HOME rev-parse --short HEAD`, but only when `git -C SWARM_HOME rev-parse --show-toplevel` is SWARM_HOME itself. Otherwise, as in the plugin cache, name the version in SWARM_HOME/.claude-plugin/plugin.json and say it is not a git checkout. The runner contract is fixed here, so no later story edits retro_report or retro_report.py. retro_report gathers every section's inputs and passes them as context: the tag, the window's day, the project and board dirs, the events.tsv and findings.tsv paths, the memory folder, and findings_open. findings_open is a file holding `out_of_scope_findings <window day>`'s output. retro-findings-list makes that function honour the day argument; until then it ignores it, and no section reads the file. retro_report then runs bin/lib/retro_report.py, a runner modelled on flow_report.py:1-40. It runs each bin/lib/retro_<name>.py in name order under `## <name>`. A section that raises prints `error: <name>: ...`, and the other sections still run. Run python3 -I with SWARM_LIB first on sys.path (tests/lib_path_test.sh). The first section is retro_memories.py: the lead's memory notes not yet placed. It prints each <dir>/*.md except MEMORY.md, with its name and its description: line. The --memory default is CLAUDE_PROJECTS (bin/lib/agents.sh:823-825) plus the main checkout's path, with each character outside A-Za-z0-9 turned into -, plus /memory. Example: this lead's folder for /Users/ehsan.ashouri/Work/swarm-dev is -Users-ehsan-ashouri-Work-swarm-dev. Read only the *.md files in that one folder, never a *.jsonl. An empty or missing folder prints a line that says so (rules.md:15). The test fixture: findings.tsv with declined and fixed rows, events.tsv with intervene, other incident and reap lines, and a memory folder.
