# dispatch runs the binary for a command with a marker file, inside the bash frame

Uses binary-find's binary_find (bin/lib/binary.sh), go-frame-entry's table, SWARMDEV_ handoff names and wrapper-fixture, make-test-binary's SWARMDEV_BIN and Go on CI, and name-readers-markers' tests/swarm_commands.sh: skill_test no longer extracts is_command, and events_test's arm loop reads the markers. It shares scripts/test-map.tsv's Go row with go-bare-swarm-scan. A marker is an empty file bin/ported/<dispatch name>, one per ported name (`_` names included), so two port PRs never edit the same line. bin/swarm.sh sources bin/lib/binary.sh with the other libs (:561-575). In dispatch, after lead_rename (:626) and before the case, a name matching ^[a-z_][a-z0-9_-]*$ with a marker goes to binary_run; no other name can reach a marker. is_command (:777) is true for a marked name, so main logs it as it logs a bash arm (:1287). binary_run gets the path from binary_find, or dies with its line. It sets every SWARMDEV_ name on each run, empty values included, so a nested swarm.sh never inherits its parent's die file: DIE_FILE is never taken from the environment (:81). The die file passes only at the command's own level (DIE_LEVEL), as die() does. stdin passes through (:1342). The binary's exit code is the command's. With no marker, nothing changes: only bash builtins on that path ([[ -e ]], no fork), since the speed job counts process starts on next, status, dash and usage. SWARM_FORBID_PROJECT (:201-211) and the shim on PATH (:229-233) already run before dispatch. Docs: the dispatch comment and a markers paragraph in docs/port/README.md. Map: add binary_dispatch_test to the Go row (scripts/test-map.tsv:52), and add a row for bin/ported/* that selects the four marker readers (doc_check, skill_test, port_names, events), binary_dispatch_test and the port list tests. binary_run passes SWARM_HOME to binary_find, so add bin/lib/binary.sh to SWARM_HOME's row in docs/port/swarm-names.tsv (critic). CI: add tests/binary_find_test.sh and tests/binary_dispatch_test.sh to macos.yml's SUBSET (macos.yml:30), so the wrapper runs under bash 3.2. That change to .github/ holds the PR for the user.
