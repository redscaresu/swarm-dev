# The differential run compares two trees on one set of fixtures

Adds tests/diff_run.sh <tree-a> <tree-b> [fixture...], the CLI every port epic runs; one case arm per option, so later stories add their own. A fixture is fx_<name> in a tests/diff_fixtures_<area>.sh file, loaded by glob from the run's own checkout, so v0.31.2's tree runs the same fixtures; it builds the project and sets the command line, env and optional stdin. Each fixture runs once per tree in a fresh root, in a process group of its own, and the run waits, with a bound, for every process left in the group. gh and herdr shims go first on PATH (and in HERDR_BIN_PATH). They log each call and answer from the fixture's stubs (merge_fixture.sh's when the fixture sources it: tests/merge_fixture.sh:28-60). They never exec a gh or herdr found on PATH: an unanswered call is logged and exits 1 with a loud line. GH_TOKEN and GITHUB_TOKEN are unset and GH_CONFIG_DIR is an empty dir. Streams: stdout, stderr, exit code, each file written under the root by path and content, and stub calls as calls:fg. Later stories add calls:<step> for background steps; these names are the contract allow-list's entries address. Exact replacements: each tree's root path, its own plugin.json version in version= (bin/lib/agents.sh:970-998), the fixture root. Fixed-shape masks: the ISO time stamp, pids, mktemp suffixes (bin/lib/merge.sh:1094,1104), and only the seconds and load columns of .swarm/run-times.tsv, which next and status append (bin/swarm.sh:751-773). Seed fixtures: usage, next and status on an empty project. Exit 0 equal, 1 with a diff per fixture and stream, 2 when a fixture fails to build. Fixtures load by glob, so no test names them and the tests/*.sh row selects only removed_test.sh (scripts/test-map.tsv:52); a row before it sends tests/diff_fixtures_*.sh to tests/diff_run_test.sh, which builds every fixture on disk. It lives under tests/, so the shellcheck and lint globs already cover it (Makefile:37-38,47).

**Done when:**
- (1) Two copies of one tree at different paths compare clean on every seed fixture, next's and status's run-times.tsv rows included. (2) With one copy changed, the run exits 1 naming the fixture and stream for each of: one byte of stdout; a stdout line moved to stderr; a changed exit code; one extra file; one byte changed in a file both trees write; a written file deleted; a run-times.tsv row's command column changed, and that row missing; one extra gh call; one extra herdr call. (3) A one-byte change on a line that also holds a masked time stamp is red. (4) An unanswered gh call exits non-zero with the shim's own line while the real gh's directory stays on PATH. (5) A gh call that a backgrounded child makes after the command exits is compared, and a process still alive past the bound is red, naming its argv. (6) tests/diff_run_test.sh checks (1)-(5). On a worktree copy without .git it goes red when any one stream's compare, the file content compare or the shim's refusal is removed. It runs in under 120 s on its CI shard, quoted in the PR.
