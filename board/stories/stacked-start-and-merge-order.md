# A story whose dependencies all have open PRs starts on their branches, and is held out of review until they merge

All the open ones must be in the story's own repo, and a gh failure leaves it blocked. It prints `ready: <slug> (stacked on <parents>)`. A blocked story whose worktree exists (a child that review held, below) is readied only once every parent is finished. touches_rows (:2336-2398) skips a story's own depends_on parents, so `story --strict` does not refuse a child whose touches overlap its parent's when the parent has no epic or another one (:2390 skips only the same epic). build_story (:2252-2304), for a ready story with open parents: fetch each parent's origin/story/<p> and check that its PR is still open. Otherwise start the worktree at origin/story/<first parent> and merge each other parent's branch; a merge conflict fails naming both branches and leaves no worktree or branch behind.
