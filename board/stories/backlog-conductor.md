# `swarm.sh conduct --backlog` builds, reviews and hands over (or merges) ready stories with no epic, as a conductor does an epic

start_conductor (bin/swarm.sh:2669-2700) takes `--backlog`; dispatch's conduct arm already passes it as the first argument (:5427), so the arm does not change. It needs no epic file, and fails with nothing started when the board has an epics/backlog.md. It starts conduct-backlog in a workspace named backlog and writes .swarm/briefs/conduct-backlog.md, so conduct_epic and conductor_report resolve it as backlog (.swarm/conduct-backlog.report.md). conduct_brief (:2423-2462) gives backlog its own opening, in place of 'You are the conductor for the epic …' (:2427-2428): it is the backlog conductor, it builds the ready stories with no `epic:`, and it reads AGENTS.md, STATUS.md if there is one and method.md first.
