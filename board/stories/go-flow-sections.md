# flow's runner runs a section that has no .py file through the binary, shown with one fixture section in Go

Needs register from go-entries-per-file. A Go section has a marker, an empty file bin/sections/flow/<name>, as a ported command has one under bin/ported/, so a runner knows its Go sections without starting anything. A rules package internal/sections holds the sections by runner, each registering from its own file, and one fixture section (fixture: true, no marker, as frame.go's fixture entries have none). The fixture prints every key of its context in order (the 12 argv keys, the row count and each row, each dep, each story) as a .py section given that context prints them, and exits with n when its epic is exit-<n>. The _section entry runs `_section flow <name> <argv...>` with the argv and environment flow_report.py gives a .py section; it needs no frame. flow_report.py lists the .py names and the marker names together in name order, or takes SWARM_FLOW_SECTIONS' names as given. It runs a Go section as `$SWARM_SECTION_BIN _section flow <name> <argv...>` under the same `## <name>` line and blank line, prints `error: <name>: exit N` for a failing exit and goes on, and fails a name that is both a .py file and a marker. A new helper section_bin <runner> in bin/lib/reports.sh prints nothing when bin/sections/<runner>/ holds no marker (compgen, no fork); otherwise binary_path's answer, or ! and its first line, which a Go section then prints as `error: <name>: <line>` while the others run. flow_sections (bin/lib/reports.sh:516-531) hands it over as SWARM_SECTION_BIN. So with no marker nothing new starts, no binary_path and no build, and a run with no Go section works with no binary and offline. binary_path's comment (bin/lib/binary.sh:226) names this caller. New SWARM_SECTION_BIN row in docs/port/swarm-names.tsv; SWARM_ROWS', SWARM_DEPS' and SWARM_STORIES' rows gain the Go file. docs/reference-logs.md § Flow and features (:324) says a section is a flow_<name>.py or a Go section with its marker, and docs/port/README.md § The markers names bin/sections/. No marker ships: the fixture is the only Go section. Marker bin/ported/_section.
