# close <name> <cause> records why a builder stopped; with goal on, an in-progress story's close needs one; impossible makes the story a lead item without an attempt

`swarm.sh close <name> [cause]` takes one of met, impossible, stalled, bound, paused or cleared-on-error, checked by is_close_cause (like is_tell_kind). An unknown cause is refused before anything closes, with a message that names the six and does not echo the given word, since main logs a die's first line. main logs `close:<cause>` with the name as target only for a valid cause, as with tell:<kind>; otherwise plain `close`. With goal on, a close with no cause is refused only when <board>/stories/<name>.md exists with status: ready (the builder is giving up). A story in review, done or gone, and a name with no story file, close with no cause as today, so conduct_merge_rule's and commands/swarm.md's closes after review or merge, and epic mode's close after finish, stay bare. A cause on a name with no story file is logged and changes nothing else. outcomes_report counts close:* as a close, and decisions_report reads close:* as a close whose chosen value is the cause. Counting follows close-counts-a-failed-build's rule for met, stalled and bound. impossible, paused and cleared-on-error skip the count but still run its cleanup helper (worktree, local and origin story/<slug>, open PRs), on the same condition: the builder is open under the slug's name and no PR merged. impossible likewise needs the builder open. It then sets kind: lead and escalated_from: <kind> with set_fm, and writes fable-failure-goes-to-you's marked block with its **You:** text passed in: fix its **Done when** (the judge called it impossible from the builder's session), then `swarm.sh reset <slug>` builds it again. The block's PR URLs come from the cleanup helper's gh output. attempts: is unchanged. Docs: method § Model and effort, the escalation bullet (impossible, paused and cleared-on-error are not attempts); method § Building, the **The audit log.** paragraph (close:<cause>); README § When /swarm stops for you (an impossible story); both stories READMEs; humanizer over them.

**Done when:**
- tests/close_test.sh: `close s1 impossible` on a ready code story with attempts: 1 and its builder open leaves kind: lead, escalated_from: code, attempts: 1, status: ready and a **You:** line naming Done when. With no builder open, it leaves the story file unchanged.
- `close s1 stalled` and `close s1 bound` raise attempts by one; `close s1 paused` and `close s1 cleared-on-error` leave it unchanged.
- `close s1 maybe` fails with a message naming the six causes and not containing 'maybe'; the pane stays in the state file; events.tsv logs it as command close, with no 'maybe' anywhere in the line.
- With goal = 5: `close s1` on a ready story fails naming the causes and closes nothing. With no cause, `close s1` closes when the story is in review and when the story file is gone, and so do `close conduct-e`, `close hld-x` and `close plan-x`. With goal off, `close s1` with no cause closes as today.
