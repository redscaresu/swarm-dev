# swarm.sh _dropped-lines runs the dropped-lines check

swarm.sh gains `_dropped-lines`, a read-only dispatch arm that runs bin/lib/dropped_lines.py with its arguments and exits with its code.
It is the seam the Go port switches (P3): dropped-go-switch points it at the binary.
The helper's usage line now names `swarm.sh _dropped-lines` in place of `dropped_lines.py`.
The base tree has no such arm, so both fixtures print swarm.sh's help text there and exit 2.
The fixtures are in tests/diff_fixtures_dropped_entry.sh.

No arguments: the usage line in place of the help text, and exit 2 on both trees.
A merge that drops a base line: that line in place of the help text, and exit 1 in place of 2.
