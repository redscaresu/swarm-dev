# Reference

The detail behind [the guide](method.md): how each step works, every rule and every log. Read the guide first.

The reference has a file per topic. A `§ <name>` in the docs, a brief or a comment means the
section of that name, in the file listed for it here.

- [`reference-lead.md`](reference-lead.md): [§ The lead](reference-lead.md#the-lead)
- [`reference-planning.md`](reference-planning.md): [§ Writing an HLD](reference-planning.md#writing-an-hld), [§ Decomposing an HLD](reference-planning.md#decomposing-an-hld), [§ Writing an epic](reference-planning.md#writing-an-epic), [§ Scoping an epic](reference-planning.md#scoping-an-epic)
- [`reference-models.md`](reference-models.md): [§ Model and effort](reference-models.md#model-and-effort), [§ Settings](reference-models.md#settings), [§ Cleanup, escalation and session logs](reference-models.md#cleanup-escalation-and-session-logs)
- [`reference-building.md`](reference-building.md): [§ Building](reference-building.md#building)
- [`reference-logs.md`](reference-logs.md): [§ Logs and outcomes](reference-logs.md#logs-and-outcomes), [§ Flow and features](reference-logs.md#flow-and-features), [§ The outer loop](reference-logs.md#the-outer-loop)
- [`reference-merging.md`](reference-merging.md): [§ Merging](reference-merging.md#merging), [§ Releases](reference-merging.md#releases)
